# Chmlfrp QQ群签到验证码图片识别程序

无OCR，纯代码识别

![示例图片 数字：1399](/materials/1399.png)

分析图片：背景色`->`噪点`->`干扰线`->`数字。数字总是完整的。

## 运作原理

1. 提取背景色，既出现次数最多的颜色
2. 排除出现次数不符合预期的颜色（噪点基本上就排掉了）
3. 线性扫描图片，碰到异色就切出图块扫描
4. 扫完按从左到右排序，输出结果

## 使用

1. 确保安装有JDK 25或更高版本。
2. 克隆到本地。
3. 用JDK 25启动`src/cn/yuang2714/chmlfrpimgdetector/Detector.java`
4. 输入图片路径，按下回车
5. 运算结果
